

# Lumka - AI-Powered VA Assistant Landing Page

## Overview
A premium, modern landing page for Lumka — an AI co-pilot platform built specifically for Virtual Assistants and Executive Assistants. The page uses a sophisticated purple/mint/coral color palette on a warm cream background, with Outfit and Inter typography.

## Page Sections (Top to Bottom)

### 1. Sticky Navigation Bar
- Lumka logo with purple gradient on the left
- Center navigation links: Features, Pricing, How It Works, FAQ (smooth scroll)
- Right side: "Sign In" text link + "Join Waitlist" coral gradient button
- Mobile hamburger menu with slide-out drawer

### 2. Hero Section
- Two-column layout (text left, visual right) on lavender-to-cream gradient background
- "Launching March 2026" eyebrow text
- Bold headline: "Stop Drowning in Tasks. Start Leading with AI."
- Subheadline explaining the value proposition
- Two CTA buttons: "Join Waitlist - Free Early Access" (coral gradient) + "Watch 2-Min Demo →" (outlined purple)
- Trust badges with mint green checkmarks (500+ VAs, 15+ hrs/week saved, tool integrations)
- Right column: Product mockup illustration showing the Lumka chat interface with floating feature cards

### 3. Problem Section
- Dark slate background with cream text for contrast
- Headline: "Being a Virtual Assistant Shouldn't Mean Being Overwhelmed"
- Three pain-point columns: Email Overload, Calendar Tetris, Repetitive Admin Hell
- Each with icon, description, and relatable copy
- Bottom quote in mint green italic

### 4. Features/Solution Section
- Five feature cards in a responsive grid: Email Guardian, Calendar Concierge, Finance Watchdog, Content Studio, Operations Lab
- Each card has icon, description, bullet-point feature list with mint checkmarks, tagline, and "Learn more" link
- Hover effects with lift animation and purple border glow

### 5. How It Works Section
- Three step cards connected by dotted line: Connect Your Tools → Chat Naturally → Watch the Magic Happen
- Numbered circle badges overlapping card tops
- Security badges, example commands box, and learning badge within cards
- Clean gray background

### 6. Before vs. After Comparison Section
- Comparison table with 7 task rows showing time savings
- Purple gradient header, alternating row backgrounds
- Red X vs mint checkmark visual indicators
- Summary box: "22.5 hours saved per week" in purple gradient card
- Responsive: converts to card stack on mobile

### 7. Pricing Section
- Five pricing cards: Free ($0), Basic ($9.99), Pro ($49 — highlighted as Most Popular), Business ($199), Enterprise (Custom)
- Pro card scaled up with "Most Popular" badge and gradient border
- Founding member 50% discount badges on paid plans
- "All Plans Include" section below with security/guarantee features
- Stripe/billing badges at bottom

### 8. Social Proof / Testimonials
- Three testimonial cards with star ratings and VA quotes
- Purple left-border accent on cards
- Stats banner in purple gradient: time savings, cost savings, feature requests count, launch date

### 9. FAQ Section
- 8-question accordion with expand/collapse animation
- Covers: AI replacement concerns, ChatGPT differentiation, security, pricing flexibility, cancellation, launch timeline, technical skills, request counting
- Purple border on hover, smooth slide-down answers

### 10. Final CTA / Waitlist Section
- Full purple gradient background
- "Ready to Stop Being Overwhelmed?" headline
- Email signup form (input + submit button, horizontal on desktop)
- Trust indicators with mint checkmarks
- Social proof counter ("87 people joined this week")
- Success state with confirmation message
- Alternative CTAs: Watch Demo, Download Brochure
- Social media links (Twitter, LinkedIn, YouTube, Instagram)

### 11. Footer
- Dark slate background, 4-column layout
- Column 1: Logo, tagline, description, copyright
- Column 2: Product links (Features, Pricing, How It Works, etc.)
- Column 3: Company links (About, Careers, Blog, Contact, etc.)
- Column 4: Legal links (Privacy, Terms, Security, etc.)

## Design Details
- **Colors**: Deep Purple (#6B46C1), Electric Violet (#8B5CF6), Mint Green (#10B981), Coral (#F59E0B), Cream (#FDFBF7), Dark Slate (#1E293B)
- **Typography**: Outfit (headlines), Inter/DM Sans (body) via Google Fonts
- **Animations**: Hover lifts on cards/buttons, smooth scroll navigation, accordion expand/collapse
- **Responsive**: Fully responsive with mobile-first considerations (hamburger nav, stacked layouts, card scrolling)
- **No backend needed**: Pure frontend landing page with a client-side email form (shows success state on submit)
